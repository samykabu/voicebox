## Basic Generation

<Steps>
  <Step title="Select Profile">
    Choose a voice profile from the dropdown
  </Step>
  <Step title="Enter Text">
    Type or paste your text
  </Step>
  <Step title="Generate">
    Click **Generate** and wait a few seconds
  </Step>
  <Step title="Play & Export">
    Preview and download the result
  </Step>
</Steps>

## Choosing an Engine

The engine picker lists every engine. An engine this computer can't run is greyed out, with a sentence saying why. It is not hidden.

The first time you use **VoxCPM2**, Voicebox asks before downloading it. The dialog shows the size (about 4.8 GB), the licence (Apache-2.0, commercial use allowed) and, if your graphics card looks short of memory, a warning. The warning does not stop you. Click **Download** to go ahead or **Cancel** to stop.

VoxCPM2 speaks 30 languages, including Arabic, Burmese, Indonesian, Khmer, Lao, Tagalog, Thai and Vietnamese. It produces 48 kHz audio.

## Voice Description

Engines that support voice design (today, VoxCPM2) show a **Voice description** box in the generate box. Describe the voice you want, for example "A calm older woman with a low, warm voice". Any language works.

- The description is used only for that generation. To keep a voice, create a designed profile instead (see [Creating Voice Profiles](/overview/creating-voice-profiles#workflow-c--designed-profiles)).
- If the selected profile has a voice recording, the recording sets the voice. The box then says the description is not being used.
- With a designed profile and an empty box, the profile's saved description is used.
- Retry and regenerate reuse a designed profile's description, but not a one-off description typed in the box.

The voice description is not the same as delivery instructions (tone, pace, emotion), which only Qwen CustomVoice supports.

## Advanced Settings

Some engines have extra settings. For VoxCPM2, click **Advanced settings** in the generate box to show two sliders:

- **Guidance** — default 2.0, range 1.0 to 3.0
- **Quality steps** — default 10, range 4 to 30. More steps take longer

The settings apply to the generation you start. They are not saved with it, so retry and regenerate use the defaults.

## Text Formatting Tips

The way you format text affects the output quality.

### Punctuation

Use proper punctuation for natural pauses:

```
Good: "Hello! How are you today? I'm doing great."
Bad: "Hello how are you today Im doing great"
```

### Emphasis

Use formatting to suggest emphasis:

```
- ALL CAPS for louder/emphasized: "That was AMAZING!"
- Italics for subtle emphasis: "I *really* enjoyed that"
- Bold for strong emphasis: "This is **very** important"
```

<Callout type="info">
  The model interprets these hints but results may vary.
</Callout>

## Advanced Features

### Batch Generation

For long-form content, split into smaller chunks for better control and faster processing.

### Voice Caching

Voicebox caches voice prompts for faster re-generation with the same profile.

## AI-Generated Label

Every audio file Voicebox generates is labelled. The WAV's metadata carries the comment "AI-generated by Voicebox". This covers saved generations, effects versions, story exports, streamed audio and the effects preview. The sound is unchanged.

Your own recordings are not labelled: voice samples you upload or record, and audio you transcribe.
