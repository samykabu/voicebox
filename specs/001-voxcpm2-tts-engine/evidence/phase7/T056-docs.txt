NOT VERIFIED / DISCREPANCIES
  - The brief says audio_to_wav_bytes is used by "/speak persist=false and MCP speak".
    The code does not support that. POST /speak (routes/speak.py:74) and MCP voicebox.speak
    (mcp_server/tools.py:250-263) both call generate_speech, which saves with save_audio,
    so their audio is labelled anyway, as a saved file. services/generation.py:396
    generate_audio_sync (docstring: "/profiles/{id}/speak ... persist=false") does return
    audio_to_wav_bytes output, but I found no caller of it outside tests, and no persist
    field on any request model. The docs name only /generate/stream and the effects preview
    for wav_bytes, and say /speak and MCP speak are saved files.
  - The "workflow-c--designed-profiles" anchor assumes the docs site's slugger turns
    "Workflow C — Designed Profiles" into that slug (github-slugger behaviour). Not rendered.
  - User-facing dialog size "about 4.8 GB" is computed from formatDownloadSize, not observed.
  - "A different seed may give a noticeably different voice from the same description" is
    based on probe.md Q9 (design steering varies between runs), not a seeded A/B test.
  - T055 changes are in the working tree from another worker, not yet committed.
  - Pre-existing inconsistencies left alone: introduction.mdx says Kokoro has 9 languages
    while other pages say 8; PROJECT_STATUS.md header and other sections are upstream's
    2026-07-02 snapshot.
